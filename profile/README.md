# Tropiro

Tropiro is building open-source authorization and evidence foundations for
vendor-authorized industrial product security in disconnected, restoreable lab
environments.

## Current project

- [RangeSpec](https://github.com/tropiro/rangespec) — a versioned manifest and
  offline CLI for scope, permitted actions, safe state, stop conditions,
  recovery evidence, approvals, redaction, and deterministic fingerprints.

## Current stage

Tropiro is an early-stage founder-led project. The open-source tooling and lab
methodology are in development. Tropiro does not currently operate a completed
industrial lab, test live systems, serve customers, or claim model-provider
program access.

Founded by [Christopher Yanez](https://github.com/chrisavor), a Computer Science
student at the University of Central Florida.
